# GitHub Pages copy of the site

The homepage is edited directly in `static/index.html`. Project pages and legacy redirects are generated by `node scripts/build-static-site.mjs` from the app in `app/` and `public/`.

| Address | File |
| --- | --- |
| `/` | `index.html`, the illustrated mountain portfolio |
| `/projects/<id>` | `projects/<id>.html`, one per project |
| `/projects`, `/outside`, `/lab`, `/daily-cafe` and the other old project addresses | Small pages that forward to the homepage or the project pages |

`.nojekyll` stops GitHub Pages running Jekyll, which would otherwise drop `assets/_vinext_fonts`.
